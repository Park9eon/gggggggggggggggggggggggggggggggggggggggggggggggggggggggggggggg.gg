# g.gg

[g.gg](https://gggggggggggggggggggggggggggggggggggggggggggggggggggggggggggggg.gg)

A monochrome ASCII animation where a central `G` becomes three smaller `G` forms. Every frame is built from a fixed-width character-density ramp: `.`, `,`, `g`, `9`, `q`, and `G`.

It has no dependencies and respects `prefers-reduced-motion`.
